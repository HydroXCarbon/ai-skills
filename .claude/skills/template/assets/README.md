# Assets

This folder holds any static file the skill ships with — prompt
templates, decision-tree diagrams, sample fixtures, images, fonts,
icons, brand assets, anything the skill reads from disk at runtime
or hands to the user as output.

Reference assets from `SKILL.md` by relative path:

```markdown
Use the template at [assets/prompt.txt](assets/prompt.txt).
Embed [assets/diagram.svg](assets/diagram.svg) in the report.
```

Delete this folder if the skill ships no static assets. Delete this
README and replace with the actual files when you do use it — the
folder existing on its own is enough to teach the layout.
